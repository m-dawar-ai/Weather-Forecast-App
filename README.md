# 🌤 Weather Forecast App

A Python-based Weather Forecast Application that provides real-time weather information and a 5-day forecast using the OpenWeather API.

## Features

- 🌡 Current Weather
- 📅 5-Day Weather Forecast
- 💧 Humidity
- 🌬 Wind Speed
- 🔽 Pressure
- 👁 Visibility
- ☁ Cloud Coverage
- 🌅 Sunrise & Sunset
- 📝 Search History
- 🗑 Clear Search History
- 📋 Menu-Driven Interface

## Technologies Used

- Python
- OpenWeather API
- Requests

## Project Structure

```
Weather_App/
│── main.py
│── weather.py
│── forecast.py
│── history.py
│── utils.py
│── menu.py
│── weather_history.txt
│── requirements.txt
│── README.md
```

## Installation

1. Clone the repository
2. Install dependencies

```
pip install -r requirements.txt
```

3. Run

```
python main.py
```
